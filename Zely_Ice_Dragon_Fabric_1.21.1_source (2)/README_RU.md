# Zely: Ice & Dragon Magic — Fabric 1.21.1

Первый прототип мода с командами способностей персонажа ZelyMars.

## Что есть в прототипе
- `/zely ice` — ледяная волна: замедляет существ в радиусе 6 блоков.
- `/zely flight` — включает полёт.
- `/zely ground` — выключает полёт.
- `/zely dragonfire` — поджигает существ поблизости и ускоряет игрока.
- `/zely invisibility` — невидимость на 8 секунд.
- `/zely ancient` — усиление скорости, силы, сопротивления и прыжка на 12 секунд.
- `/zely help` — список способностей.

## Сборка
Нужен JDK 21 и подключение к интернету для загрузки зависимостей Gradle.
1. Открой папку проекта в IntelliJ IDEA как Gradle-проект.
2. Дождись загрузки зависимостей.
3. Запусти задачу Gradle `build`.
4. Готовый JAR появится в `build/libs/`.
5. Для игры нужны Minecraft Java 1.21.1, Fabric Loader и Fabric API той же версии. Положи JAR мода в папку `mods`.

## Важно
Это исходный прототип, а не уже собранный и протестированный `.jar`. В этой версии способности запускаются командами; следующие этапы — добавить клавиши, визуальные эффекты, звуки, кулдауны и собственные текстуры.
